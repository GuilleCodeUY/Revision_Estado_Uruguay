# Investigación · Puerto de Montevideo

Un archivo por tema. En cada uno: el prompt para DeepSeek, el lugar para pegar su respuesta y la verificación de Claude.

Cómo se usa:
1. Copiá el prompt del tema a DeepSeek (de a uno).
2. Pegá la respuesta completa en la sección "Respuesta de DeepSeek" del mismo archivo y guardá.
3. Avisale a Claude qué temas están listos: verifica cada dato, marca lo que falla y completa lo que falte.
