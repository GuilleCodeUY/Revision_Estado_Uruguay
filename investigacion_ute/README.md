# Investigación · UTE

Caso 5 del sitio: gastos, ganancias y pérdidas de UTE, lo que pagamos por la energía y cuánto debería costar.

Un archivo por tema. En cada uno: el prompt para DeepSeek, el lugar para su respuesta y la verificación de Claude.

Cómo se usa:
1. Hermes (DeepSeek) lee el prompt de cada archivo, investiga y guarda su respuesta en la sección "Respuesta de DeepSeek".
2. Avisale a Claude qué temas están listos: verifica cada dato, marca lo que falla y completa lo que falte.
